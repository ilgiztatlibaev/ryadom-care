# Рядом — тревожная кнопка

Адаптивный одностраничный сайт услуги экстренного реагирования для пожилых людей. Рабочее название бренда — «Рядом».

Сайт на GitHub Pages: https://ilgiztatlibaev.github.io/ryadom-care/

## Просмотр и проверка

`npm run dev` запускает сайт на http://localhost:5173. `npm run check` проверяет JavaScript, `npm run build` собирает копию в `dist/` и проверяет наличие всех ресурсов.

Сайт не требует внешних библиотек. Изображение и шрифты сохранены локально. Навигация, мобильное меню, вкладки, FAQ, интерактивный сценарий и валидация формы работают в браузере.

## Перед приёмом реальных заявок

Форма демонстрационная: ничего не отправляет и не сохраняет. Для запуска нужно подключить приём заявок, добавить реальные контакты и сведения об операторе персональных данных. Подтвердить тарифы, регион обслуживания и порядок реагирования. Отзывы и конкретные показатели скорости реагирования не выдумывались.

## Изображение

`public/assets/family-hero.webp` — иллюстрация, созданная встроенным ImageGen и оптимизированная для сайта. Промпт: естественная редакционная фотография пожилой женщины в шалфейном кардигане с взрослой дочерью в светлой блузке; держатся за руки в солнечном домашнем интерьере, тёплая палитра ivory/olive, естественные улыбки, без текста и логотипов. Изображение иллюстративное.

## Публикация

GitHub Pages публикует каталог `public` через `.github/workflows/pages.yml`. Каждый push в `main` обновляет сайт. Относительные пути ресурсов работают и в подкаталоге `/ryadom-care/`, и в корне домена.

Привязка к Sites хранится в `.openai/hosting.json`; развёртывается собранный каталог `dist`. Архив публикации создаётся из сборки точного коммита исходников после Git push. Краткоживущий credential передаётся `tools/push-source.mjs` только через stdin и окружение дочернего Git-процесса, не записывается на диск.
